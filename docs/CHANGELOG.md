## 版本規範

我們使用 [Semantic Versioning](https://semver.org/) 進行版本管理：

- **主版本號**：不兼容的 API 變更
- **次版本號**：向下兼容的功能新增
- **修訂號**：向下兼容的問題修復

## 提交類型

- `feat`：新功能
- `fix`：錯誤修復
- `docs`：文檔更新
- `style`：代碼格式調整
- `refactor`：代碼重構
- `test`：測試相關
- `chore`：建置過程或輔助工具的變動
